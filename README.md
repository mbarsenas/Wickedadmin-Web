# WickedAdmin Web

Static company website for WickedAdmin LLC.

## Local preview

Open `index.html` directly, or serve the directory with any static HTTP server.

## Deployment

The site has no build step and can be deployed to GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any conventional web host.

Before production cutover, confirm the `wickedadmin.com` DNS target and replace the temporary Gmail contact link with a verified WickedAdmin company alias when available.
